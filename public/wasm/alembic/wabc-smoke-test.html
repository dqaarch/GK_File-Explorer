wabc WASM Smoke Test (Phase 3)

Verifies that /wasm/alembic/wabc.js + wabc.wasm compile against the full Alembic SDK via i-saint's wabc::SceneABC and expose the Phase 3 C ABI:

  • wabc_open_buffer (now path-based) / wabc_close
  • wabc_get_start_time / wabc_get_end_time / wabc_seek
  • wabc_get_num_vertices / wabc_get_num_faces
  • wabc_read_positions / wabc_read_face_counts / wabc_read_face_indices
  • wabc_read_expanded_vertices / wabc_read_wireframe_indices
  • wabc_get_num_points / wabc_read_points
  • wabc_get_num_cameras / wabc_read_camera / wabc_get_camera_path
  • wabc_get_time / wabc_cleanup

Note: wabc_open_buffer is path-based (the C++ side opens the file with std::fstream). To test with a real .abc file, point the input below at a path reachable by the C++ side. In a Tauri/webview context, the file must be on the local filesystem; over http:// only files inside the dev server document root are accessible to the wasm.
